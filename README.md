
# YouTube Best Video Finder

A query-aware system that ranks YouTube videos by usefulness,
using metadata, multilingual comment analysis, content signals,
and learning-to-rank.

## Project Status
Phase 0 — Planning and Setup

## Planned Features
- YouTube Data API v3 candidate collection
- Metadata and comment intelligence
- Query-aware video ranking
- Evidence-based explanations and warnings
- FastAPI backend and web application

## Tech Stack
Python, pandas, NumPy, scikit-learn, LightGBM,
Hugging Face Transformers, FastAPI, SQLite.

## Setup
Setup instructions will be added after the environment
and API collector have been verified.

## Evaluation
The primary ranking metric will be NDCG@5, alongside
Precision@5 and comparisons with baseline rankings.
